# 测试计划

## 测试依据

固定代码是需求来源，README 仅作线索。`weapon_db.gd` 定义五枪数据；`weapon_manager.gd` 决定输入、共享冷却、换弹、射线与同队过滤；`player.gd` / `bot.gd` 决定受击、死亡、复活；`net.gd` / `world.gd` 决定名册、握手和同步权限。

普通有限弹药：开火 mag 减 1；换弹从 reserve 转移至 mag，上限 mag_size，总量守恒。部分备用不足则尽量补充；满弹/无备用/正在换弹拒绝重复请求。空仓触发自动换弹，未产生射击。换弹中无法开火，切有效枪槽取消换弹；切空槽/非法槽不改变当前动作。冷却跨枪保留。半自动按住只发一枪，松开再按可再次开火。手枪 infinite=true 只代表无限备用，弹夹仍消耗；reserve=0 仍可补满。

真实玩家与 bot 的 Hitbox 倍率为 head 2.5、torso 1、legs 0.75。武器基础伤害为 rifle17/smg12/pistol24/sniper95，shotgun 每弹丸9、9弹丸。HIT_MASK=world(1)|hitbox(16)；世界障碍先命中会遮挡，同队不受伤也不穿透。狙击射程300m。bot 死亡血量归零、hitbox layer清零、重复受击不再次加分。玩家 PvP 不使用 bot 伤害折扣。

## 风险与优先级

| 风险 | 影响 | 策略 |
|---|---|---|
| 换弹/切换/卸载竞争 | 异常、弹药丢失或复制 | P0，状态交叉与守恒 |
| 自动/半自动输入及共享冷却 | 射速错误、切枪绕过冷却 | P1，明确分段时间推进 |
| 无限备用被套普通守恒 | 假失败或错误设计 | 单独验证真实换弹路径 |
| 身体部位、障碍、同队 | 命中判定与公平性 | 真实物理射线，明确目标几何 |
| 随机散布 | 不稳定结果 | 每例 seed=20261113，近距离中心瞄准，保留原武器数据 |
| 权限与不同端状态分歧 | 客户端显示与实际受伤不一致 | 双进程独立快照、期限轮询 |
| 离线角色残留 | 幽灵目标、向离线peer发RPC | P0，名册/世界/计分板一致性 |
| 错误退出码与缺失报告 | CI假绿 | 原始进程状态+错误日志+用例清单三重门禁 |

## 隔离与判定

每个玩法场景新建玩家，重置 Game.config/scores/match_active，销毁前例 actor，固定随机种子。暂停玩家输入/运动和 bot AI，以确定性 delta 调用**生产**武器 `_process`；没有模拟另一套换弹公式。弹药等初值在操作前设置，操作后只读结果。场景末尾等待真实 FX 协程完成并清理节点。

联机保持生产玩家 physics/synchronizer 正常运行；arena地图、0bot，避免 AI 把静止测试玩家击杀。主机准备好后 Python 才启动客户端，脚本按实际状态而非固定“已等待足够久”判定。主机等待客户端快照并比较 peer id、authority、team、name、HP 和武器索引。N06只检查主机清理，客户端只清理自己的测试场景，不能替主机删除残留。

准入：固定引擎与干净上游；导入无 ERROR。退出：全部32场景出现一次且断言成功，所有子进程未超时且退出0，无 SCRIPT ERROR/ERROR，JSON可解析且计数一致。JUnit可额外包含基础设施失败节点，不能将这些当新增玩法数量。

## 人工与未覆盖

保留人工用例：主菜单 ComfyUI 准备与失败提示；实际画面/头部对齐；换弹动画和切枪手感；受击反馈；音量与混音；死亡/复活视觉。此次均**未执行完整人工验收**，不能写成通过。

不测弱网、反作弊、预测纠偏、长时压力、加入进行中的对局、断线重连、所有地图/模式、所有装备perk组合。N07仅验证大厅阶段服务器断开后客户端网络对象/名册清理；不验证对局中断开后的整套UI跳转。射程检查为299/301m两侧，未验证精确端点浮点语义。固定种子不等于散布的概率分布正确。
